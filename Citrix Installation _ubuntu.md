# Citrix Installation for ubuntu

## Step 1: Download the .deb Packages ([here](https://www.citrix.com/downloads/citrix-secure-access/plug-ins/Citrix-Gateway-VPN-EPA-Clients-Ubuntu.html))
Download the Citrix Secure Access client (nsginstaller64.deb)

```bash
sudo apt install ./nsginstaller64.deb
sudo apt install -f
```


## Step 2: Install via Terminal
Open your terminal in the directory where the files were downloaded and run the following commands:
```bash
sudo apt install ./nsginstaller64.deb
sudo apt install -f
```
